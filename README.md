
# 📄 AI Resume Analyzer

An AI-based Resume Analyzer developed using Python, NLP, and Streamlit.

## 🎯 Project Aim

The main aim of this project is to automatically extract important
information from a candidate's resume and present it in a structured
format.

## ✨ Features

- Upload resume in PDF format
- Extract candidate name
- Extract email address
- Extract phone number
- Extract technical skills
- Calculate resume score
- Display extracted resume text
- Download extracted text

## 🛠️ Technologies Used

- Python
- Streamlit
- spaCy
- PyPDF2
- Regular Expressions

## 🔄 Project Workflow

Resume PDF  
→ Text Extraction  
→ NLP and Regex Processing  
→ Information Extraction  
→ Resume Score  
→ Display Results
